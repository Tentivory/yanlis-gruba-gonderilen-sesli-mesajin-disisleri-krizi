# Yanlış Gruba Gönderilen Sesli Mesajın Dışişleri Krizi

## T.C. Dışişleri Bakanlığı — Acil Nota Verbale Masası

Bu yazılım, WhatsApp, Telegram veya benzeri bir uygulamada **yanlış gruba sesli mesaj** gönderildiğinde otomatik olarak toplanan, hiç kimsenin davet etmediği, herkesin ciddiyetle oturduğu **Dışişleri Kriz Masasıdır**.

Sesli mesaj artık evrak değildir.  
Sesli mesaj **nota verbaledir**.  
Grup yöneticisi **büyükelçidir**.  
"Bu mesaj silindi" yazısı **1961 Viyana Diplomatik İlişkiler Sözleşmesi Ek-7**'dir.  
Mavi tik **onay mührüdür**. Çift mavi tik **karşılıklı tanımadır**.  
Ses kaydının 0:07 saniyesindeki öksürük **gizli ek protokoldür**.

## Kurulum

```bash
python3 kriz_masasi.py
```

Bağımlılık yoktur. Çünkü kriz masaları bağımlılık kabul etmez; sadece çay kabul eder.

## Kullanım

Program senden şunları ister:

1. Sesli mesajın süresi (saniye)
2. Yanlış giden grubun resmi adı
3. Aslında gitmesi gereken kişi / grup
4. Mesajın ilk üç kelimesi (sansürlü yazabilirsin)

Ardından şunları üretir:

- Kriz seviyesi (YEŞİL / SARI / TURUNCU / KIRMIZI / ULUSLARARASI UTANÇ)
- Resmi nota verbale metni
- "Silindi" operasyonunun başarı olasılığı
- Büyükelçi (grup yöneticisi) için taziye cümlesi
- Gizli arşiv kodu

## Yasal Uyarı

Bulunsa bile WhatsApp sunucuları bunu ciddiye almaz.  
Alsa bile senin annen yine de duymuştur.
